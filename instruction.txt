### Laravel Backend
cd api
composer install
# Create the database and configure the .env file
php artisan migrate
php artisan serve --host=0.0.0.0 --port=8000


### React Native / Expo
cd mobile
npm expo install

For local testing:
npx expo start

For testing from another network/country:
npx expo start --tunnel
-But i think A local API URL only works on the same local network.

# Press "a" to run the app on the Android Emulator


### Note

The app is configured to use the local Laravel API:
http://10.0.2.2:8000/api

Therefore, the app is currently intended to run on the Android Emulator.
A physical device will require a different API URL using the laptop's local IP address.
